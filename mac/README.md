# DeskPet 🐣 — macOS 版

一个原生 macOS 桌面宠物：上传一张照片，AI 把它变成卡通形象，头顶带着血条。
你的坏习惯会变成对它的攻击 —— 熬夜、久坐，HP 就往下掉；好好睡一觉，它才能恢复。

## 构建 & 运行

```bash
cd mac
./build_app.sh        # 只需 Command Line Tools，无需 Xcode
open DeskPet.app      # 或直接运行 DeskPet.app/Contents/MacOS/DeskPet
```

宠物出现在屏幕右下角，菜单栏显示 ❤️ HP。

- **拖动**：按住宠物任意位置
- **双击**：戳它一下
- **右键 / 菜单栏图标**：切换攻击特效、测试一次攻击、回满血、设置、隐藏宠物、退出（形象、状态图、配置等都在「设置」里）

## 通用设置

设置 →「通用」：

- **开机启动**：登录 macOS 时自动打开 DeskPet（使用系统登录项）。首次开启时可能需要在「系统设置 → 通用 → 登录项」里允许；移动 DeskPet.app 之后要重新打开这个开关。
- **语言**：跟随系统 / 简体中文 / English。菜单、设置、血量看板、宠物说的话都会立即切换，不用重启；发给 AI 的提示词始终是英文。

## 规则（都可以在「设置」里改）

| 规则 | 默认 | 效果 |
|---|---|---|
| 熬夜 | 00:00–06:00 期间有键鼠操作 | 每分钟 -2 HP |
| 久坐 | 连续使用 > 90 分钟（离开 5 分钟算休息） | 每分钟 -1 HP |
| 好好睡觉 | 整个宵禁时段没违规 | 早上 +30 HP |

## 攻击特效

每次扣血是一套连击，HP 随每一下命中逐段下降。右键 → 攻击特效（或 设置 →「形象」）选择预设，右键菜单里选中会自动预览（不扣血），设置里点「试一下」：

- ⚡️ **雷击**：乌云聚集，紫色闪电连劈 3 次，触电闪光
- 🖐️ **连环耳光**：左右开弓最多 6 下，人物被打歪，「啪!」
- 🥫 **丢易拉罐**：易拉罐抛物线砸头（压扁 + 💫），然后弹飞
- 🎲 **随机**

惩罚触发后，威胁会**持续留在宠物身边**，直到最后一次惩罚 3 分钟后才退场（还在违规就一直在）：

- ⚡️ 乌云不散，云里时不时闪紫色雷光
- 🥫 远处站着一个小人，把易拉罐抛起又接住；攻击时就是他在扔
- 🖐️ 一只手悬在旁边摩拳擦掌，偶尔空挥一下

HP 归零宠物会倒下 💤，只有按时睡一晚才能复活。
"是否在用电脑" 通过系统空闲时间判断（>120 秒无输入 = 离开），不需要任何系统权限。

## 卡通形象与状态图

宠物有 4 张状态图：**满血 / 残血（HP<30）/ 受击（连击过程中）/ 阵亡**。缺少的状态用滤镜效果代替（变灰、倒下、染红）。

- **AI 生成**（设置 →「素材生成」）：从照片生成满血形象后，会以它为参考自动生成另外 3 张，保证是同一个角色。也可以单独重新生成某一张。
- **导入现成的图**：设置 →「形象」，每个状态都能单独导入（建议透明背景 PNG）。
- **服务商**（设置 →「素材生成」顶部的「AI 设置」：服务商 / Key / 模型 / 代理）：
  - OpenAI 兼容接口（默认 `gpt-image-1`，透明背景）；改 Base URL / 模型名可接任何兼容服务
  - Google Gemini（默认 `gemini-2.5-flash-image`，在 aistudio.google.com 免费拿 Key）；白底会自动抠成透明
  - 模型名可自由输入，也可从「预设」里选
- **提示词**：在「素材生成」里每一行点「提示词」展开编辑，清空或点「恢复默认」回到默认值。
- **代理**：可在设置里填；不填则使用 `HTTPS_PROXY` 环境变量。
- 未配置 Key 时，满血形象退回本地 Core Image 卡通滤镜。

## 特效素材

设置 →「素材生成」可以给乌云、扔罐小人（待机 / 抛起 / 投掷）、易拉罐、巴掌换上插画素材，没有的继续用代码绘制：

- **AI 生成**：提示词预置了模仿 cindy.app 的日系插画风格（细墨线、赛璐璐、红蓝轮廓光、排线质感）。小人的「抛起」「投掷」以「待机」为参考生成，保证是同一个人。
- **复制提示词 + 导入**：没有 API Key 时，复制提示词到 Gemini / ChatGPT 网页版生成，再导入（建议透明背景 PNG）。
- 风格描述和每个素材的描述都可以在「素材生成」里改；界面（血条、气泡、伤害数字）也使用同一套红 / 黑 / 蓝配色。

## 素材库：生成和选择分开

- **「素材生成」页**只负责生成：每个素材一行（提示词、复制提示词、生成）。生成结果不会覆盖旧图，而是按类型存进素材库，并自动设为当前使用。
- **「形象」页**只负责选择：宠物状态图，以及攻击特效（雷击 / 连环耳光 / 丢易拉罐 / 随机）。选中某个特效后，下面才展开它用到的素材（雷击→乌云，耳光→巴掌，易拉罐→罐子 + 小人三个姿势，随机→全部）。每种素材列出它文件夹里的所有图，点一下就换；也可以选「滤镜效果」/「代码绘制」不用图片。右键图片可以在 Finder 中显示或删除（移到废纸篓）。
- 素材库位于 `~/Library/Application Support/DeskPet/Library/`，结构固定：

  ```
  Library/
    pet/normal  pet/low  pet/hurt  pet/dead
    fx/cloud  fx/thrower-idle  fx/thrower-toss  fx/thrower-throw  fx/can  fx/hand
  ```

  文件名为 `<类型>_<yyyyMMdd-HHmmss>.png`，导入的图带 `_import` 后缀。直接把图片拖进对应文件夹也行，回到设置窗口时会自动出现在列表里。
- **内置默认素材**：App 自带一套猫猫状态图（满血 / 不高兴 / 哈气 / 睡觉）和特效插画（乌云、扔罐小人三个姿势、易拉罐），放在仓库根目录的 `assets/defaults/` 下（和 Windows 版共用），结构和素材库一样。首次启动时各复制一份进素材库（`<类型>_default.png`），某类还没选图时自动选中；之后就是普通的库文件，取消选择或删除都会保留你的选择。巴掌没有内置图，继续用代码绘制。
- 旧版本的 `pet.png`、`pet_hurt.png`、`fx_cloud.png` 等会在首次启动时搬进对应文件夹（`<类型>_legacy.png`），并保持选中。

## 血量看板

右键 →「血量看板…」（或 设置 →「记录」）查看最近 30 天的**每日最低血量**折线图，附今日最低、30 天平均、最低的一天、低于残血线的天数；可切换为表格。悬停查看每天的数值。

数据存在 `~/Library/Application Support/DeskPet/hp_history.json`，每天一条 `{"day": "2026-11-01", "minHP": 47}`：每次血量变化都会更新当天最低值，跨天时以前一天结束时的血量作为新一天的起点。App 没运行的日子没有记录，折线会在那里断开。

## 导入 / 导出配置

设置 →「备份」→「导出配置… / 导入配置…」。一个 JSON 文件包含整套配置：

- 四张状态图（内嵌在文件里）、规则、攻击特效、服务商与模型、提示词
- API Key 默认不导出，导出时可勾选；导入的文件不含 Key 时保留现有 Key
- 不包含当前 HP、扣血记录、代理和窗口位置

导入时文件里的图会作为新文件存进素材库并选中；文件里没有的状态图 / 素材会切回滤镜效果 / 代码绘制（库里的旧图不删），导入前会确认。

## 代码结构

- `BehaviorMonitor.swift` — 每分钟检测一次，规则引擎（新规则加在 `tick()` 里）
- `PetStore.swift` — HP / 形象 / 日志状态与持久化
- `AssetLibrary.swift` — 素材库：按类型分文件夹存图、记录每种素材当前选中的文件、迁移旧文件
- `Attacks.swift` — 攻击预设（连击次数/节奏）和各特效组件（乌云、闪电、巴掌、易拉罐）
- `PetView.swift` — 宠物、血条，命中反馈（白闪 + 顿帧 + 弹簧回弹）
- `FX.swift` — 粒子系统（火花 / 碎屑 / 尘土 / 冲击环 / 电弧）、漫画爆炸框、伤害数字、闪光、细雨
- `LayerLoop.swift` — 用 Core Animation 跑的循环动画（呼吸待机、残血心跳），空闲时 App 几乎不占 CPU
- `ImageStylizer.swift` — OpenAI / Gemini 图像接口、白底抠图、本地卡通滤镜
- `PoseGenerator.swift` — 从照片创建形象、并行生成状态图
- `ConfigTransfer.swift` — 整套配置的导入导出（含状态图和特效素材）
- `EffectAssets.swift` — 特效素材定义、默认提示词、Cindy 配色
- `HPHistory.swift` — 每日最低血量记录（hp_history.json）
- `DashboardView.swift` — 血量看板（Swift Charts）
- `Localization.swift` — 界面语言：文案写成 `L("中文", "English")`，放在用到的地方
- `SettingsView.swift`、`AppDelegate.swift`、`Prefs.swift`

数据位置：`~/Library/Application Support/DeskPet/`（素材在 `Library/` 下），设置在 `defaults read com.deskpet.app`。
